# WMC native prototype

An independent Godot 4.4.1 project, not an APK WebView and not a replacement for the existing game. It is a **performance/feel prototype**, not a complete game. It uses the existing six approximate circuit centrelines and Ducati and rider assets; the road geometry and controls are approximate; the acceleration, steering, reverse and track boundaries follow the website formulas but are not a full port of the authoritative multiplayer physics.

## Test it

The `Build native prototype` GitHub Actions workflow builds a Windows EXE and an Android debug APK. Download the two named artifacts from a successful workflow run. The Windows artifact contains `WMC.exe` and `WMC.pck`; keep both together. Its engine template matches the symbolized test build that was reported to run without the crash, but omits the large symbols file. The Android debug APK is signed with a CI-generated debug key, so it is for testing, not Play Store release; a later CI run may not install over an earlier one unless you uninstall it first. Windows may show a SmartScreen warning for an unsigned EXE. Back up any device data before uninstalling. This prototype can read the signed-in rider profile, but it does not award points.

Use W / up for gas, S / down to brake, Space for hard braking, and A/D or arrows to steer on Windows. Press Escape to pause or resume. Android uses on-screen driving controls and a pause button. The pause menu offers Resume and Main Menu. The FPS counter is the native game frame rate. The engine sound is synthesized from the same waveform and RPM formula as the website; the menu sound toggle controls both engine and music.

**Important:** Replay uses recorded rendered frames rather than a video file or reconstructed positions; it is local only and does not encode or share a video. Practice races support 1–10 laps, a 1–4× practice simulation speed, six circuits, five start lights, a live circuit map and nine optional local AI riders. The timing tower displays live positions and animates order changes. Riders are held on the grid until the red lights go out. The AI follows the circuit with simplified speed control and does not yet implement bike-to-bike collisions. After the player finishes, the native results sequence cues the website soundtrack at 20 seconds, displays Grand Prix results at 23 seconds, shows championship unavailable for practice at 43 seconds, and transitions to a winner card after 63 seconds. This is an approximation of the web presentation. A separate camera records actual race-world frames to a bounded temporary JPEG ring (up to the latest 7 seconds) for one-time winner-screen playback, followed by a held final frame and the winner card; it follows the current leader and includes any other riders in view. Capture adapts up to 60 fps based on GPU readback cost and game FPS, and may record fewer frames to protect race performance; it has no audio and is not a complete race recording. The results use a separate animated rider viewport. Unfinished AI are labelled unfinished and practice points are not recorded. Settings include master, music and engine volume, replay capture (default on; takes effect next race), plus PC-only GUI scale. Temporarily disable replay capture to compare race performance and isolate capture-related crashes; no frames are recorded while disabled. Multiplayer, qualifying, networking, and championship scoring remain unimplemented. Use it to decide whether a full migration is worth pursuing, not as a replacement for the current game.

## Local build

Open `native-prototype/project.godot` with Godot 4.4.1. Install the matching export templates and Android SDK/JDK 17 in Godot editor settings, then export using the Windows and Android presets. The GitHub workflow documents a repeatable CI build.

The opening screen and soundtrack are native approximations of the web menu. Play opens mode selection; multiplayer and qualifying are disabled until implemented. Practice race settings apply when a circuit is selected. Hold Space for hard braking; controls use no keyboard focus to prevent Space activating UI buttons. The camera now banks subtly with the bike as in the web game. The native Google sign-in uses your system browser and PKCE, keeping tokens only in memory and retrieving your existing rider profile; you can edit or create the rider profile from the native menu. It uses an app-local callback on port 18674, so browser or device restrictions may affect it and real Windows/Android sign-in testing is required. Signing out clears the prototype's in-memory token; your browser's Google session is not signed out.


### Crash diagnostics
On Windows, `WMC-diagnostics.txt` is written next to `WMC.exe` if the folder is writable, otherwise in `%APPDATA%/Godot/app_userdata/WMC/`. Android stores it in the app's private user data. It records startup, race state every five seconds, and clean shutdowns; no clean exit after a session can indicate an abrupt termination, though a log cannot identify every native/GPU crash. Godot's separate engine/script log is `logs/godot.log` under that same application data directory. Attach both logs after a crash if possible. Logs do not include profile names or credentials.

On Windows with replay capture enabled, `WMC-capture-gpu.txt` and `WMC-capture-encoder.txt` beside the diagnostics file record the most recent capture/encoder operation. If the game crashes, copy them before starting another race, along with the engine log and diagnostics. They are intended to help locate a native crash, not to prove its cause.

### AI model detail
The nine AI riders use simplified versions of the existing bike and rider geometry; the player retains the originals. Texture images, node names and transforms are unchanged. To reproduce the AI meshes with `@gltf-transform/cli` 4.2.1 (meshoptimizer), run `gltf-transform weld` on each source GLB, then `gltf-transform simplify` on the welded bike with `--ratio 0.40 --error 0.005` and on the rider with `--ratio 0.50 --error 0.005`. Run `python3 native-prototype/tools/check_ai_models.py` to check the assets. Replay still captures the actual race scene, including AI.
